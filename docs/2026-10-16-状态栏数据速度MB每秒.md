# 状态栏数据速度（MB/s）显示

- 日期：2026-10-16
- 涉及目录：`HMCB_Qt/src/ui/MainWindow.{h,cpp}`
- Windows 参考实现：`HMCB-H_DLL_TEST V1.4.2.4_20260319_HMCB4/TEST/MCB_TESTView.cpp`

## 1. 需求

在 Qt 版状态栏中添加"当前数据速度"显示，单位 **MB/s**（兆字节/秒）。

## 2. Windows 版参考逻辑（MCB_TESTView.cpp）

### 2.1 显示位置与格式

状态栏 Pane 3（`MainFrm.cpp:77`，宽 230px）：

```
Rate:%8.3fMb/s  avg:%8.3fMb/s
```

仅当 `m_bStart`（采集中）且 `m_MCBScount[m_nMCB] != 0`（已有样本）时刷新（`MCB_TESTView.cpp:1844-1884`）。

### 2.2 算法

每帧数据位数（`MCB_TESTView.cpp:1867-1873`）：

```
fSumPerMCBRate[i] = m_nMCBADNum[i] × m_nDMChNum × m_nADBit
                  = nDMNum × (nRowNum × nColNum) × adBit        // bit/帧/板
fSumRate = Σ 各在线板
```

HMCB4 实配（25 DM × 32 行 × 4 列 × 16bit）= 51200 bit = 6400 B/帧。

速率（`MCB_TESTView.cpp:1874-1881`，`m_uCnt` = 当前帧头 `scounter`）：

```
瞬时 = (m_uCnt − m_uCnt0) × fSumRate / (t  × 1000)   // Mb/s，t  = 距上次 OnTimer 的 ms
平均 =  m_uCnt          × fSumRate / (t1 × 1000)     // Mb/s，t1 = 自 Start 起的 ms
```

复位时机（`OnMcbStart`，`MCB_TESTView.cpp:749-757`）：每次 Start 时
`t/t0/tstart` 重取当前时间、`m_uCnt/m_uCnt0` 清零、Pane 3 清空。
`m_nADBit` 由 DVREADY 后 `GETDMADBIT` 填入（缺省 20，实机 16）。

注意：Windows 依赖实机每轮 START 后 `scounter` 从 1 重新计数（数据回调
`MCB_TESTView.cpp:822-826` 以 `scounter==1` 判本轮首帧），平均速率直接用
绝对 `scounter` 计算。

## 3. Qt 版实现

### 3.1 状态栏（buildStatusBar）

由 5 格增至 6 格，速度格插入在 fps 之后（对照 Windows Pane 顺序
RunTime→Rate→DI）：

```
[RUN 3s] [9 fps] [Rate: 0.074 MB/s avg: 0.075 MB/s] [123 帧] [DI: 0x…] [状态]
```

固定最小宽 230px（同 Windows Pane 3），避免每秒文本跳动。未采集显示
`-- MB/s`（对照 Windows Start 时清空 Pane 3）。

### 3.2 数据源与计算（MainWindow 1Hz rateTimer 内）

- **每帧位数** `m_speedBitsPerFrame`：DVREADY 后按 `getMcbNum()` 遍历
  `getDmInfo(b)` 求 `Σ nDMNum×nRowNum×nColNum×adBit`（adBit 取
  `McbController::adBit()`，Controller 在 emit deviceReady 前已由
  GETDMADBIT 更新，见 `McbController.cpp:46-55`）。
- **瞬时/平均**：同 Windows 公式，`scounter` 取帧回调缓存的 `m_lastSC`；
  时间用 `QElapsedTimer`（`m_speedClock` 自 Start 计时，
  `m_speedLastMs` 为上次 tick 的累计毫秒，对应 Windows 的 t/t1）。
- **单位换算**：Windows 显示 Mb/s，本需求要求 MB/s → `bit/帧 ÷ 8e6` 得
  MB/帧后再除以秒。
- **刷新门控**：`rateTimer` 仅采集运行时启动（对照 `m_bStart`），
  速度格仅在 `m_speedBitsPerFrame>0 && m_lastSC>0` 时更新（对照
  `m_MCBScount` 非零门控）；停止后保留最后显示值（Windows 同）。

### 3.3 与 Windows 的有意差异

| 点 | Windows | Qt 版 | 原因 |
|---|---|---|---|
| 平均速率样本基数 | 绝对 scounter | 本轮首帧 scounter 起的差值+1 | 实机每轮 scounter 从 1 起，两者数值相同；mock 后端 scounter 跨轮累加、真机重连不复位，差值法更稳 |
| 回绕/设备重启 | 无防护（显示负值/异常） | `scounter < 基点` 时重置基点 | 断电重连场景（见断电重连文档）下避免持续显示错误值 |
| 单位 | Mb/s（兆位） | MB/s（兆字节，÷8） | 本需求指定 |
| 更新周期 | OnTimer 1s（低配机 1.5s，`MCB_TESTView.cpp:365-367`） | QTimer 1s | 已有 rateTimer 统一节拍 |

## 4. 验证

- `ctest`：14/14 通过（不涉及 MainWindow，仅回归）。
- offscreen 冒烟（mock，25DM×128ch×20bit=8000B/帧，~9fps）：
  状态栏显示 `Rate: 0.074 MB/s avg: 0.075 MB/s`，与 9×8000B≈0.072MB/s 吻合
  （首次 tick 含启动段略高属预期）。
- 真机模式启动确认状态栏 6 格布局正常（未长跑，避免打扰在线设备）。
